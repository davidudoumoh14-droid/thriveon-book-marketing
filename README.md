# Thriveon – Book Marketing Agency Website

Professional multi-page website for a book marketing agency offering a custom 90-day book marketing roadmap with guided email support.

## Core Offer

| Package | Price | Highlights |
| --- | --- | --- |
| Basic | $899 | Custom 90-day roadmap, templates, email support, 2 progress reviews |
| Advanced | $1,899 | Everything in Basic + multi-channel plan, messaging guide, priority support, 3 reviews |
| Premium | $2,699 | Everything in Advanced + 90+30 day roadmap, content calendar, sales funnel outline, highest priority support |

All plans are delivered digitally. Support is email-only. No live one-on-one consultation calls.

## Pages

- `index.html` – Homepage
- `services.html` – 90-Day Roadmap details & process
- `pricing.html` – Full package comparison
- `about.html` – Agency story & values
- `submit.html` – Author application form (includes package preference)
- `contact.html` – Contact form

## Design

- Navy + white + gold
- Fredoka + Inter
- Fully responsive

## Deploy to GitHub Pages

1. Push this repo to GitHub.
2. In GitHub, open the repository.
3. Go to Settings → Pages.
4. Set source to the default branch (`main`) and `/ (root)`.
5. Save.

Your site will be published at:

`https://<your-username>.github.io/thriveon-book-marketing/`
